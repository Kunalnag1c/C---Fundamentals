# C Programming Practice

This repository contains my practice programs written in the C language.  
The goal of this project is to strengthen my understanding of C programming fundamentals by solving various problems and building small programs.

## 📚 Topics Covered

The programs in this repository cover the following topics:

- Basic Input/Output
- Variables and Data Types
- Conditional Statements (if, if-else, switch)
- Loops (for, while, do-while)
- Functions
- Arrays
- Strings
- Pointers (basic level)
- Pattern Printing
- Recursion
